# Supply Chain Analytics Dashboard

## 1. Project Overview

This project analyzes supply chain operations using Power BI to monitor purchasing activities, supplier performance, product costs, and delivery efficiency.

The objective is to provide actionable insights that support better procurement decisions, inventory management, and operational efficiency.

## 2. Tools and Technologies

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX
- Data Visualization

## 4. Key Performance Indicators

- Total Orders: 500

- Delayed Orders: 143
- Urgent Orders: 116
- On-Time Delivery: 51%
- Urgent Order Rate: 23%
- High-Value Order Rate: 36%

## 5. Key Insights

- Supplier performance varies across the purchasing network.
- Delivery delays indicate opportunities to improve procurement planning.
- Certain products account for a larger share of purchasing costs.
- Location-level analysis helps identify differences in purchasing activities.
- Monthly trends help monitor changes in supply chain spending.

## 6. Recommendations

- Improve supplier evaluation and monitoring.
- Strengthen delivery tracking and follow-up.
- Optimize purchasing quantities.
- Monitor high-cost products.
- Improve procurement planning and inventory control.

## 7. Project Objective

To transform raw supply chain data into meaningful business insights through interactive dashboards and data analytics.
